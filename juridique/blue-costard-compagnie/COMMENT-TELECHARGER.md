# Comment obtenir les fichiers Word sur votre Bureau

## Pourquoi vous voyez « Binary file is not supported »

Ce message vient de **Cursor** : l’éditeur ne peut **pas ouvrir** les fichiers Word (`.docx`) ni les ZIP à l’écran.  
Ce n’est **pas** que le fichier est cassé. Les fichiers Word sont bien valides.

Pour les modifier, il faut les **télécharger** puis les ouvrir avec **Microsoft Word** (ou Google Docs).

---

## Méthode rapide (recommandée)

1. Dans la liste de fichiers à droite, **clic droit** sur un fichier `.docx`
2. Choisissez **Download** / **Télécharger**
3. Une fois téléchargé, glissez-le sur votre **Bureau**
4. Double-clic → il s’ouvre dans Word
5. Modifiez les zones `[ENTRE CROCHETS]`, puis imprimez

Faites la même chose pour les 3 fichiers :

- `1-Objet-social-Blue-Costard-Compagnie.docx`
- `2-Statuts-SASU-Blue-Costard-Compagnie.docx`
- `3-Fiche-a-completer-Blue-Costard-Compagnie.docx`
