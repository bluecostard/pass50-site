## Conseils enregistrement

- **Format** : MP3, M4A ou WAV
- **Durée** : 10–20 s par message (naturel, pas trop rapide)
- **Environnement** : peu d’écho, pas de musique de fond
- **Ton** : direct, comme si tu parlais à un ami sur TikTok
- **Micro** : téléphone suffit si c’est proche et calme
